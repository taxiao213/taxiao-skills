# 公众号推文 → 小红书图文笔记

## 工作流程

1. **提取**：运行脚本，在推文同级生成 `XHS/` 目录

   ```bash
   python3 scripts/extract_article.py <推文.html>
   ```

   产出 `XHS/article.txt`（正文）、`XHS/images/img_XX.jpg`（全部内嵌图）、`XHS/qr_scan.txt`（二维码检测，需 cv2）。

2. **图片分类**：逐张阅读 `images/` 中的图，按 [references/xhs-guide.md](references/xhs-guide.md) 第 3 节分类处理——截图重命名保留、装饰图删除、站外二维码移入 `不使用_站外二维码/`。**不要只信 qr_scan.txt，必须亲眼过图**（小程序码可能漏检）。

3. **改写文案**：读 `article.txt`，按 xhs-guide.md 第 1、2 节的平台规则和文案风格改写。红线：标题 ≤20 字、正文 ≤1000 字、正文零外链、零站外二维码、零导流词；获取方式一律改为评论区置顶引导。

4. **输出**：按 xhs-guide.md 第 4 节模板写 `XHS/小红书图集文案.md`（标题备选 / 图集顺序图注 / 正文 / 评论区话术 / Checklist / 视频第二波建议）。

5. **汇报**：告知用户输出位置、哪张图需打码、哪些素材被隔离。

## 注意

- 截图若自带大字标题（他晓排版风格），优先直接作图集，首张作封面。
- 视频 vs 图文的选择：工具/教程类默认图文；有强演示性内容时，在"后续第二波"里给视频思路，不主动做视频。
- 品牌物料（logo、头像）可留作尾图，但社群/公众号引流内容一律不进小红书版本。
