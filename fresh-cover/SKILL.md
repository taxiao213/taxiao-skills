# 清新极简封面生成

固定流程：**复制模板 → 填内容 → render.sh 出图 → 校验**。

## 设计原则（先读这个再动手）

封面按「3 秒扫读」设计，信息预算从严：

- **只保留 4 层信息**：分类标签（kicker）→ 钩子大标题 → 一句转折/主线（lead）→ 2~4 个关键词胶囊（chips）
- **砍掉**：顶栏路径装饰、两行式详情卡片、多层页脚小字。细节留给视频内容，封面不负责讲清楚
- 标题里的否定词/反常识词优先用**手绘删除线**（.strike）表达，比红色文字更直观
- 底部最多留一行悬念小字（teaser），如「目标形态：骨架 · 插槽 · 逃逸舱」
- 头像用**圆形裁切 + 虚线圆环**，默认**不带任何身份文字**；身份标签（如「他晓 · 用 AI 做鸿蒙 App」）只在选题与标签强相关时才加，加在 chips 下方而不是头像上

## 工作流

1. 复制 `assets/cover-template.html` 到用户的产出目录，按主题填内容：
   - 替换所有 `{{TOKEN}}` 占位符（标题、删除线词、转折句、关键词胶囊、头像路径等）
   - `{{WIDTH}}`/`{{HEIGHT}}` 按目标平台填（见下方尺寸表），并与 render.sh 参数一致
   - 配色只改 `:root` 里的 CSS 变量；默认清新自然（奶白底 + 嫩绿 + 赤陶）
   - 关键词胶囊（.chip）2-4 个，格式「领域词 · 动作词」
   - 不需要删除线时：删除 `.strike` 相关元素，标题整体用主文字色
   - 不需要头像时：删除 `.avatar` 和 `.avatar-ring` 两段
2. 出图（**必须用绝对路径**，相对路径会得到 ERR_INVALID_URL 的空白截图）：
   ```bash
   scripts/render.sh "$PWD/<产出目录>/cover.html" "$PWD/<产出目录>/cover.png" 1920 1080
   ```
3. 校验：脚本检查尺寸；再用 Read 工具查看 PNG，确认无文字溢出、无遮挡、删除线压在目标词上
4. 迭代：改 HTML 后重跑 render.sh 覆盖同名 PNG 即可

## 平台尺寸

| 平台 / 画幅 | 宽高 | render.sh 参数 |
|------------|------|----------------|
| 横屏：抖音 / 视频号 / B站 | 1920×1080 (16:9) | `1920 1080` |
| 横屏：小红书 | 1440×1080 (4:3) | `1440 1080` |
| 竖屏：抖音 / 视频号 / B站 | 1080×1920 (9:16) | `1080 1920` |
| 竖屏：小红书 / 抖音竖封面 | 1080×1440 (3:4) | `1080 1440` |
| YouTube 缩略图 | 1920×1080 (1080p) | `1920 1080` |
| 合集/播单封面 | 1080×1080 (1:1) | `1080 1080` |

同一内容做多平台时，复制多份 HTML 分别调尺寸和字号密度，输出 `cover.png` / `cover-xhs.png` 区分。
横屏默认布局：左侧文字区（kicker/标题/lead/chips）+ 右侧圆形头像；竖屏布局见 `assets/cover-template-3x4.html`（上下结构：头像缩小放右上、chips 改全宽横条）。

**抖音需要两张封面**：横封面 4:3（1440×1080）+ 竖封面 3:4（1080×1440），别只出一张。

**YouTube 缩略图特殊规则**：
- 信息流显示尺寸小 → 文案减半：只留 kicker + 大标题（≤2 行），砍掉 lead/chips/teaser
- **右下角有时长角标**：头像/关键元素避开右下角（底边留 ≥100px），放垂直居中偏右
- 可加一行英文小钩子（如 "NOT just a prompt swap."）配合双语标题
- 标题字号参考：100-110px @1280×720；出 1080p 时整体等比 ×1.5

> 缩放踩坑：旧稿从 1280×720 升 1080p 时，**不要用 `zoom` 整体放大**——Chrome 对 zoom 后 `right/bottom` 绝对定位有 bug，右侧头像会丢。正确做法是把所有 px 值 ×1.5（注意 `html,body` 尺寸、`border-radius: 999px` 这类不能被连带缩放）。

**合集封面打法**：主标题就是合集名（超大字，不需要钩子），副题定系列调性，chips 标定内容范围；kicker 用「系列合集 · 持续更新」，后续可改「已更 N 集」。

## 默认配色（清新自然）

```
--bg: #F6F4EC       奶白纸感底
--text: #25372B     深绿灰
--accent: #3E9E5F   嫩绿（kicker / lead / 关键词主词）
--accent-soft: #E4F2E4
--danger: #DF6B4F   赤陶（删除线 / 否定词）
氛围：薄荷绿 + 蜜桃色柔光团（radial-gradient blob）+ 圆点纸纹
```

## 关键规则（踩坑记录，务必遵守）

- **render.sh 必须传绝对路径**，脚本内部拼 `file://$HTML`，相对路径会渲染出"无法访问此网站"
- **body 必须精确等于画布尺寸**（`html, body { width: Wpx; height: Hpx }`），与截图窗口参数一致
- **用 `overflow-x: clip`，不要用 `overflow: hidden`**——否则浏览器预览时无法滚动
- 删除线用 `.strike::after` 绝对定位横条（rotate -2.5deg），不要用 `text-decoration: line-through`——太细太规整，没有手绘感
- 头像裁圆用 `border-radius: 50%` + `overflow: hidden` + `object-position: center N%` 调取景；不要用 `transform: scale()`
- 头像图片用相对路径引用，源文件本身不裁剪、不覆盖
- **不覆盖已有成品**：新方案复制新文件（如 `cover-v2.html`），保留原 HTML 和 PNG
- 字号参考（1920×1080 横屏）：标题 140-150px，lead 44-48px，chips 34-36px，teaser 26-28px；1440×1080 按比例 ×0.78

## 变体

- 删除线可选，适合「不是 X」「别再 X」这类打假/反常识标题
- chips 可换成单行关键词分隔符形式（词 · 词 · 词），更省空间
- 横屏右侧不放头像时，chips 可拉满整行，或右侧放内容相关的简单图形（手绘箭头、圈注）
