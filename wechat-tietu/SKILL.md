# 公众号贴图物料生成（wechat-tietu）

固定流程：**读逐字稿提要点 → 填海报模板 → render.sh 出图 → Read 校验 → 写文案 md**。已被 EP3（`docs/2026/0919/`）验证。

## 与相邻 skill 的分工

- **wechat-tietu（本 skill）**：公众号「图片」类型，一张 3:4 信息图 + 短 caption
- **taxiao-wechat-v3+**：公众号「文章」类型，长文 HTML 推文
- **fresh-cover / pip-cover**：视频封面，不管公众号

## 输入

- 口播逐字稿（或大纲）路径
- 输出目录：当集日期目录 `docs/2026/MMDD/`
- 合集上下文：第几集、下集预告一句话（底脚要用）

## 产出（两个文件）

```
docs/2026/MMDD/wechat-img-src/cover-3x4.html + .png   # 单张 3:4 信息图
docs/2026/MMDD/wechat-贴图文案.md                      # 标题候选 + caption + 发布备注
```

## ① 信息图规格与结构

- **尺寸**：基底 684×912 + `zoom:2` → render.sh 传 **1368×1824**（精确 3:4，2x 高清）
- **配色**（蓝系，沿用勿改）：主蓝 #1976D2 / 浅蓝底 #E3F2FD / 卡片底 #F0F7FF、边框 #BBDEFB；问题红 #C0392B、红底 #FBEBE9；警示黄底 #FFF8E6 边 #F5D98B 字 #8D6E1F；深色条 #1A2332（金句用，强调字 #90CAF9/#EF9A9A）；正文 #1A2332、次要 #718096
- **字体**：大标题 Georgia + 'Noto Serif SC' serif；正文 -apple-system/PingFang SC；代码 'SF Mono'/Menlo
- **结构骨架**（自上而下，内容预算从严）：
  1. chip 胶囊：「AI Agent · 工程认知 ｜ 第 N 集 · 主题」
  2. 钩子大标题：**必须一行**，684 宽下 ≤44px；数字/否定词用红色 `<em>`
  3. lead 一句转折（主蓝色）
  4. 2~4 个分区，每个分区 = 灰色小标签（`① 核心对立 ｜ …`）+ 内容块。常用块型：左右对比双卡（红 vs 蓝）、编号清单行（蓝色圆序号 + 代码行）、关键词胶囊行（3 个并排）、黄色便签（反直觉点）
  5. 深色金句条：本集金句，两行以内
  6. 底脚 `margin-top:auto`：左签名「我是他晓，在一线用 AI 做产品」，右「下集 EP(N+1) · 主题 →」
- 模板：`assets/poster-template.html`，替换 `{{TOKEN}}`；分区块按需增删（2~4 个，多了砍）

## ② 出图与校验

```bash
R=<仓库>/fresh-cover/scripts/render.sh
"$R" "$PWD/docs/2026/MMDD/wechat-img-src/cover-3x4.html" "$PWD/docs/2026/MMDD/wechat-img-src/cover-3x4.png" 1368 1824
```

- render.sh **必须绝对路径**；批量渲染逐条显式执行（zsh `set -- $var` 不分词）
- **Read PNG 校验**：无溢出（底脚和金句条完整可见）、无遮挡、标题没换行
- 溢出处理顺序：① 降分区间距（.sec margin-top 20→16）② 降行块 padding ③ 降标题字号。**不要**让标题换行或裁掉底脚
- 底部留白过多（底脚被 margin-top:auto 推远）：反向操作——加字号/间距，或补一个分区块（黄色便签最适合补位）

## ③ 文案 md 结构（已验证骨架，勿改）

1. 头部：发布类型、配图路径、源稿路径
2. **标题候选 5 个**（推荐款打 ★，延续合集钩子结构，如「给 AI 喂了 20 条上下文，15 条是噪音」）
3. **caption 直接粘贴版**：贴图正文限约 1000 字，目标 ~480 字；结构 = 钩子 → 对比 → 方法清单 → 金句 → 合集签名。图片已承载要点，caption 做展开补充，不逐图解释
4. 配图说明表（文件 / 内容 / 尺寸）
5. 发布备注：置顶评论赠品（扣关键词送板书 PNG/对比图）、与视频号联动一篇两吃、改字重渲命令

## 验收清单

- [ ] PNG 精确 3:4（1368×1824），Read 校验无溢出/无遮挡/标题一行
- [ ] 图中分区 ≤4 个，金句条与底脚（签名+下集预告）都在
- [ ] 文案：标题候选 5 个带 ★ 推荐、caption ≤1000 字、发布备注含赠品与联动
- [ ] 废弃方案（如多图卡片）保留但标注「废弃勿用」，不删文件
