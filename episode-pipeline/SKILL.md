# 单期视频全流程生产线（episode-pipeline）

「他晓」每期视频的固定产出流水线。**九步：大纲 → 逐字稿 → 去AI化 → 确认闸 → 板书 → 示例图(可选) → 批量创作（封面/文案/推文/贴图）→ 录制 → SRT 校准**，每步都有验收点，顺序不要乱；**确认闸未获用户批准不得继续**（2026-10-11 按用户定稿改版，原为七步无确认闸、发布物料在录制前最后一步）。

## 输入（开工前确认）

- 选题与钩子（一句话反常/数字冲击，如「翻 20 个文件一行没改」「20 条上下文 15 条噪音」）
- 合集状态：第几集、上集留下的钩子是什么（开场要回扣）、本集给下集埋什么钩子
- 案例载体：默认 DropLink 连传实战（源码 `~/workspace/ai_project/harmony/Transmission/`）
- 选题类型：**鸿蒙选题**才带身份标签「他晓 · 用 AI 做鸿蒙 App」；Agent 认知类不带

## 目录约定

```
docs/2026/MMDD/                # 每期一个目录
  <主题>-演讲大纲.md
  <主题>-口播逐字稿.md
  excalidraw/<主题>-板书.excalidraw + 板书大纲.md
  <主题>-context-compare.html/png   # 可选：对比示例图
  cards/                       # 封面 HTML 源 + PNG 成品（含公众号 dev 封面源）
  publish-copy.md              # 小红书/抖音/视频号
  youtube-publish-en.md        # YouTube 英文包（Chapters 先估时间，录制后 SRT 校准）
  <主题>_公众号推文.html + _复制粘贴版.html + _assets/   # 公众号文章（含双封面）
  wechat-img-src/cover-3x4.png + wechat-贴图文案.md     # 公众号贴图（可选）
  videos/                      # 录制后：成片 mp4（不入库）+ <录制日>/字幕 SRT
```

规划中期的素材先放规划目录（如 `0915/`），进制作期再移入当集日期目录。**不覆盖已有成品**，新方案一律新文件（-v2、-yt 后缀）。

## ① 演讲大纲

结构模板（对齐 EP3 `ep3-上下文工程-演讲大纲.md`）：

```
目标听众 / 建议时长 / 核心记忆点（一句话）
一、开场钩子（约 1 分钟）：回扣上集 → 抛现象 → 一句话立论
二~五、主体段：每段一个论点，配 DropLink 实例
六、收尾 + 预告：金句复述 + 下集钩子
```

## ② 口播逐字稿

- 篇幅：5~6 分钟 ≈ 1500 字，按 300 字/分钟换算并在头部标注
- 格式：【】内为提词提示（不念），分段标题对齐大纲
- 必有元素：开场回扣上集钩子 / 他晓签名「我是他晓，我们下期见」/ 下集钩子
- 数字要具体（20 条、15 条、0.94、#8FA396→#5B7266），不堆形容词

## ③ 逐字稿去 AI 化（强制，勿跳过）

朗读一遍砍书面腔：破折号长句拆短、加口语碎词（"最要命的是什么？""记住这条，等下要考"）、删掉机械排比、每处断言落到真实细节。

## ④ 【人工确认闸】标题 + 封面内容方案（2026-10-11 流程改版新增）

**位置：去 AI 化之后、板书之前**——板书大标题、全平台封面、发布文案、推文标题全都依赖主题名，先确认再往下，避免批量返工。

产物两类，**用 AskUserQuestion 带预览呈现**（沿用 1011 做法：多候选主题名 + 封面版式要素预览），一次确认全渠道对齐：

1. **标题方案**：公众号长标题（如「鸿蒙NEXT字节码还原工具：安装包直接还原成 ArkTS 源码」）+ 小红书 ★ 标题 / 抖音标题（≤20 字钩子）/ 视频号标题 + YouTube 中英标题走向
2. **封面内容方案**：各平台版式要素（主题大字、hook 条目 2~4 条、teaser）+ 头像用哪张 / 要不要身份标签 / 要不要人物 + 色调风格（清新 fresh-cover or 深色 pip-cover）

**硬规则：用户明确批准前，不得进入 ⑤ 及以后任何步骤**（不产板书、不渲封面、不写文案/推文/贴图）。确认结果留痕 CLAUDE.md 当集条目（主题名称 + 封面方案要点），后续步骤直接引用。

## ⑤ Excalidraw 板书

原则：**字少（每节点 ≤10 字）、边讲边画、画面随口播生长**。细节在嘴上不在板上。

1. 先写板书大纲（落笔顺序对齐口播段落 + 全图布局预览 ASCII）
2. 用 `assets/excalidraw-board-gen.py` 为模板生成 `.excalidraw`（复制改坐标文案；内置文本宽度估算 + 矩形溢出自检）
3. 样式约定（沿用，勿改）：
   - 配色：红 #DF6B4F = 问题/反例，绿 #3E9E5F = 做法，灰 #6B7B6F/#7A8B7D = 结构，深绿灰 #25372B = 正文
   - 填充：#FBEBE4 / #E4F2E4 / #EDEBE2；底 `viewBackgroundColor: #F6F4EC`
   - fontFamily 5（Excalifont）、roughness 1、strokeWidth 2、roundness {type:3}（矩形）/{type:2}（线）
   - 标题删除线用 line 元素斜压，不用文字装饰线
4. 校验：生成器自检无溢出后，用 assets 里的近似渲染出 PNG 肉眼核对布局
5. 录屏前待办（写进 publish-copy 备注）：在 Excalidraw 打开核对取景（autoResize 会微调文字框），导出 PNG（2x）作「扣板书」赠品

## ⑥ 对比示例图（可选，有"两份东西并排对比"段落时做）

- 1920×1080 HTML（沿用 fresh-cover 配色 + .mono 代码行），render.sh 出 PNG
- **HTML 加交互层**（滚轮缩放/拖拽平移/双击复位），供录屏取景推进特写；transform 实现，stage 固定 1920×1080
- ⚠️ headless Chrome 出图坑：页面加载瞬间视口是 1920×993（截图前才 resize 回 1080），`navigator.webdriver=false`。操作提示等浮层**只在用户首次交互后显示**，别按加载时 innerHeight 判断
- 逐字稿对比段加提词提示：【切示例图 xxx.png】

## ⑦ 批量创作（确认闸通过后开工）

### 封面图

**调用 fresh-cover skill**（Agent 认知类清新风；鸿蒙深色竖版用 pip-cover），内容编排：

- kicker｜h1 主题大字（用确认闸定稿的主题名，与合集前集同构）｜lead 转折句（手绘删除线压否定词）｜chips 2~4 个方法关键词｜teaser（可选）
- 规格（出 5 张）：抖音横 1440×1080 + 抖音竖 1080×1440 + 小红书 1440×1080 + 视频号 1920×1080 + YouTube 1920×1080 简化版（砍 lead/chips/teaser，加英文小钩子，头像 translateY(-56%) 避开右下时长角标）
- **B站双比例：同风格 + 独立文件**（2026-10-16 两次修正）：播放页 16:9 与列表页 4:3 必须**同一版式产线出**（如都走抖音 V2 实拍版式：4:3 直出 + 16:9 放大版，16:9 人物特写更大、大标题改三行短行避人脸），**禁止清新风 16:9 × 实拍风 4:3 混搭**（1015 期踩坑）；落成 `cover-bili-16x9.png` / `cover-bili-4x3.png` 独立文件（重做 -v2 递增留档）；上传双稿分别传、**不勾**【双比例同步改动】（勾了互相覆盖）——细节见 fresh-cover「B站封面特殊规则」
- **抖音两张必走 pip-cover `assets/douyin/` 的 V2 + V3 双版**（共 4 张供用户挑选）：V2=实拍打底+大字白底胶囊，V3=人物放大首层+文字后置；防「截屏当封面」flag（终端风/UI 截图/人物太小均中招，界面帧也算）。小红书横版复用抖音横其一即可，其余平台用标准版
- 头像相对路径引用（`../../0903/taxiao.png` 或当集实拍照片），源文件不裁剪不覆盖；无头像/无身份标签等按确认闸定稿执行（身份标签仅鸿蒙选题且用户要求时才有）
- render.sh 必须传**绝对路径**；批量渲染逐条显式执行（zsh 的 `set -- $var` 不分词）
- 每张 PNG 用 Read 校验：无溢出/无遮挡/删除线压对词/头像取景

### 发布文案（两份文件，结构已验证勿改骨架）

`publish-copy.md`：
- 小红书：标题候选 4 个（≤20 字，推荐款用确认闸定稿的主题名）+ 精简正文（钩子+对比+方法论）+ `<details>` 详细版（图文笔记用）+ 发布备注
- 抖音：标题 3 个 + 描述（**核心反转句压前两行防折叠**）+ 备注（双封面都上传；发布时间工作日 12-13 / 18-22，或周日晚 19:30-20:30 首发测钩子）
- 视频号：教程向标题（带"附实战对照"）+ 描述 + 备注（挂合集、挂公众号推文、标签 3-6 个）
- B站：标题（≤80 字，钩子公式=数字+反差+利益，写给路人不是同行）+ 简介（首行放钩子句=搜索权重位，正文可复用视频号/公众号素材）+ Tags ≤10（可改）+ 话题 ≤1（**投后不可改**）+ 备注（分区单选**投后不可改**：编程/开发类建议 知识区·计算机技术 或 科技数码·软件应用，上传时确认；封面双稿（16:9+4:3 独立文件）分别上传、不勾【双比例同步改动】；定时发布窗口 当前+2h ~ +15天）
- 发布顺序：抖音 → 2h 后小红书（周日 21:00 充电档）→ 视频号 → B站（沉淀位，与 YouTube 同档）→ 小红书追加图文笔记（封面+板书 PNG+详细版，一篇两吃）→ YouTube 顺手发 / X 只发 thread+图
- 有互动钩子的期：「扣板书」赠品清单写进备注；无互动钩子期：置顶评论=一句话总结引导

`youtube-publish-en.md`：
- 标题：中文钩子 + "|" + 英文 3~8 词浓缩（与封面英文钩子一致），另备一条纯英文 A/B
- 简介：EN 一段 + 中文一段 + Chapters（**先按逐字稿分段估时间戳，标注「待 SRT 校准」**）+ Key takeaways + 签名 + tags
- Tags：中英混合一行
- **英文字幕翻译稿**：逐段对齐口播稿，保留口语节奏不逐字直译（成片 SRT 出来后逐条翻译生成 .srt）

### 公众号文章 + 贴图

- 文章：走 **taxiao-wechat-v3** skill（标题=确认闸定稿的公众号长标题；两步流程 + --no-watermark-removal）；**双封面**——cover.png = Pillow 浅色四主题 + cover-dev.png = 深色 dev 模板 + render.sh 900×383，发布时二选一上传
- 贴图（可选，用户要发「图片」类型时）：走 **wechat-tietu** skill，产出 3:4 单张信息图 + 贴图文案 md

## ⑧ 录制视频

- 录屏规格 1920×1080 / 30fps / 8-12Mbps H.264；口播稿【】提词提示对准板书/示例图切换
- 录屏前待办见 ⑤ 板书第 5 条（Excalidraw 核对取景 + 导出 PNG 2x 作「扣板书」赠品，写进 publish-copy 备注）
- 产出成片 mp4 + 字幕 SRT（放 `videos/<录制日>/`，mp4 不入库，SRT 入库）

## ⑨ 录制后收尾（SRT 校准 + 发布）

1. **校准 YouTube 文案时间**：拿真实字幕 SRT 逐 cue 复核，更新 `youtube-publish-en.md` 的 Chapters 与段落参考稿时间戳；**标题/简介/Tags 不动**。成片与口播稿常见差异（新增演示段、口误修正、段落增删）都要在 Chapters 里反映
2. 更新 CLAUDE.md 当集进度（已录制 + 成片时长 + SRT cue 数 + 校准后章节锚点）
3. 按 publish-copy.md 顺序发布

## 收尾

- 更新 CLAUDE.md「各期进度」对应集的状态与产出清单（含确认闸定稿的主题名称）
- 有新书面的踩坑（工具 quirk、渲染问题）写进记忆或对应 skill 的踩坑记录
