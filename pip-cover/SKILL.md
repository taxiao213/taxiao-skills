# 画中画头像封面生成

固定流程：**复制模板 → 填内容 → render.sh 出图 → 校验**。

## 工作流

1. 复制 `assets/cover-template.html` 到用户的产出目录，按主题填内容：
   - 替换所有 `{{TOKEN}}` 占位符（标题、要点卡片、头像路径、身份标签、页脚等）
   - `{{WIDTH}}`/`{{HEIGHT}}` 按目标平台填（见下方尺寸表），并与 render.sh 参数保持一致
   - 配色只改 `:root` 里的 CSS 变量；默认深色开发者风格，可按主题换色系
   - 要点卡片（.hook）2-4 条，保持"第一行原因 + 第二行红色结果"的两行结构
2. 出图（**必须用绝对路径**，相对路径会得到 ERR_INVALID_URL 的"无法访问此网站"截图）：
   ```bash
   scripts/render.sh "$PWD/<产出目录>/cover.html" "$PWD/<产出目录>/cover.png" 1080 1920
   ```
3. 校验：脚本会检查尺寸；再用 Read 工具查看 PNG，确认无文字溢出、无遮挡、头像取景合适
4. 迭代：改 HTML 后重跑 render.sh 覆盖同名 PNG 即可

## 平台尺寸

| 平台 | 宽高 | render.sh 参数 |
|------|------|----------------|
| 抖音 / 视频号 / B站竖版 | 1080×1920 (9:16) | `1080 1920` |
| 小红书 | 1080×1440 (3:4) | `1080 1440` |

同一内容做多平台时，复制两份 HTML 分别调尺寸和布局密度，输出 `cover.png` / `cover-xhs.png` 区分。

## 抖音封面特供：V2 / V3 双版并行（防「截屏当封面」flag）

抖音封面审核启发式会判「截屏当封面」并降流量，已实锤的命中特征：
- 深色终端风（网格底、窗口栏、等宽代码感）→ 判软件截图（0926）
- **视频界面帧当封面**（如版本号/About 面板）→ 判截屏（1011）
- 人物占比太小（画中画小窗头像约 20%）→ 提示「人物要放大」（1011）

**规则：凡发布抖音，横（1440×1080）竖（1080×1440）各出 V2 + V3 共 4 张供用户挑选**；小红书复用横版其一，视频号/B站/YouTube 不受影响、继续用本模板标准版。

| 版本 | 版式 | 模板 | 适用 |
|------|------|------|------|
| V2 | 实拍照片全幅打底 + 大字压字 + 白底胶囊（0930 起源） | `assets/douyin/cover-dy-4x3-v2.html`、`cover-dy-3x4-v2.html` | 想突出主题大字；照片人物偏小或取景一般 |
| V3 | 人物放大首层 + 文字后置（1011 起源） | `assets/douyin/cover-dy-4x3-v3.html`、`cover-dy-3x4-v3.html` | 突出人设/口播类；人物照质量高 |

**V3 版式要点**（同一张实拍照片两层用法）：
- 底层：`blur(24px) brightness(.42)` 暗化版做文字底；容器 `inset:-40px` 防 blur 露边
- 首层人物：`object-fit:cover` 裁切放大（横版头部约占画面高 70%）+ `mask-image` 羽化边缘探进文字区 + `drop-shadow` 立体
- 「文字在人物后面」= 文字层 z-index 低于人物层；**羽化带内文字被逐级盖住：羽化带前 1/3 可读、后 2/3 全盖**——想压住哪行文字，把该行尾缘伸进羽化带前段（alpha 0~30% 区）
- 竖版 hook 胶囊位置随标题行数变化需重新核算（行数变少 → 胶囊下移进羽化带过多会被盖没）
- 零 UI 元素：无网格、无窗口栏、无圆点、无截图

**V2 版式要点**：照片 `width:120%` 右移避让左侧文字区，左侧柔光渐变 + 底部渐变保证可读，文字一律白底胶囊/投影，零终端元素。

## 关键规则（踩坑记录，务必遵守）

- **body 必须精确等于画布尺寸**（`html, body { width: Wpx; height: Hpx }`），截图窗口参数与之相同
- **用 `overflow-x: clip`，不要用 `overflow: hidden`**——否则用户在浏览器预览时无法滚动
- **头像放大用 `width: 118%` + 负 margin + `object-fit: cover`**，不要用 `transform: scale()`——缩放元素会创建层叠上下文，盖住窗口的标题栏和底栏
- 头像取景用 `object-position: center N%`（N 越小越靠上，头肩特写一般 15-22%）
- 窗口标题栏长标签加 `white-space: nowrap`，装不下就减 font-size，不要让它换行
- 头像图片用相对路径引用（如 `../taxiao.png`），头像源文件本身不裁剪、不覆盖
- 印章 `.stamp` 的 `top/right` 是按 4 字主标题调的，标题更长时下移或右移，避免压住标题文字
- **不覆盖已有成品**：新方案复制新文件（如 `cover-avatar.html`），保留原 HTML 和 PNG

## 变体

- 不需要头像时，整段删除 `.pip` 块，要点卡片 `.hooks` 的 `width` 改为 100%
- 印章 `.stamp` 可选，适合"已整改/已解决/Rejected"这类强情绪词
- 页脚右侧适合放账号名/产品名/技术栈等 mono 小字

## 兄弟 skill

需要**清新自然浅色风格**、**横屏封面**、**YouTube 缩略图**或**方形合集封面**时，改用 `fresh-cover`（同为仓库根目录 skill），本模板专注深色开发者风格竖版。
